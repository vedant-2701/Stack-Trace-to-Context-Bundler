- A zero-frame exception header uses a distinct bracket form -- `[ClassName: message]` -- instead of the plain `ClassName: message` form; util.inspect only emits this when there's no "at" stack to render inline (confirmed via `logged-object-fetch-cause.txt`'s outer node, `zero-stack-trace-limit.txt`, `aggregate-error-uncaught.txt`).
